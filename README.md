# 🩺 DermaAI — AI-Powered Skin Disease Classification

**DermaAI** is a full-stack **AI-powered skin disease classification system** that uses **Deep Learning and Computer Vision** to analyze skin images and predict possible skin conditions with confidence scores.

The project combines a **React frontend**, **Node.js backend**, **MongoDB Atlas**, and a **Python FastAPI machine-learning service** powered by **EfficientNet-B0**.

> ⚠️ **Disclaimer:** DermaAI is an educational and research project and is **not intended to provide medical diagnosis or replace professional medical advice.**

---

## 🔍 About the Project

Skin disease classification is an important application of **Artificial Intelligence, Machine Learning, Deep Learning, and Computer Vision**.

DermaAI allows users to upload a skin image and receive an AI-generated classification result. The system processes the image through a trained deep-learning model and returns the predicted class along with confidence information.

The project demonstrates how a machine-learning model can be integrated into a complete production-style web application.

# 🧠 Machine Learning Model

DermaAI uses **EfficientNet-B0**, a convolutional neural network architecture designed to provide a strong balance between computational efficiency and classification performance.

### ML Pipeline

```text
Skin Image
    ↓
Image Preprocessing
    ↓
Resize / Normalization
    ↓
EfficientNet-B0
    ↓
Feature Extraction
    ↓
Classification Layer
    ↓
Prediction Probabilities
    ↓
Top Prediction
    ↓
Confidence Score
```

The trained model is exposed through a **FastAPI inference service**, allowing the Node.js backend to communicate with the machine-learning model through an API.

# 📊 Machine Learning Workflow

The machine-learning pipeline follows these general steps:

### 1. Dataset Collection

Skin disease images are collected and organized into appropriate disease categories.

### 2. Dataset Preparation

Images are cleaned, organized, preprocessed, and prepared for model training.

### 3. Dataset Splitting

The dataset is divided into:

```text
Training Dataset
       +
Validation Dataset
       +
Testing Dataset
```

### 4. Image Preprocessing

Images are resized and normalized before being passed to the neural network.

### 5. Model Training

EfficientNet-B0 is trained/fine-tuned on the prepared dataset.

### 6. Model Evaluation

The trained model is evaluated using classification performance metrics.

### 7. Model Deployment

The trained model is exposed through a Python FastAPI service.

### 8. Application Integration

The React frontend communicates with the Node.js backend, which communicates with the FastAPI machine-learning service.

# 🚀 Running the Project

## 1. Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/DermaAI.git

cd DermaAI
```

## 2. Install Frontend Dependencies

```bash
cd frontend
npm install
```

Start the frontend:

```bash
npm run dev
```

Frontend:

```text
http://localhost:5173
```

---

## 3. Install Backend Dependencies

```bash
cd backend
npm install
```

Start the Node.js server:

```bash
npm start
```

Backend:

```text
http://localhost:5000
```

---

## 4. Run the ML Service

Navigate to the machine-learning service:

```bash
cd ml
```

Install Python dependencies:

```bash
pip install -r requirements.txt
```

Start FastAPI:

```bash
uvicorn main:app --reload --port 8000
```

ML API:

```text
http://localhost:8000
```
